# 📦 Controle de Estoque - Loja de Eletrônicos

Projeto desenvolvido em Excel para simulação e controle de estoque de uma loja de produtos eletrônicos.

## 🎯 Objetivo

Criar uma ferramenta simples para acompanhar entradas, saídas,
estoque atual e disponibilidade dos produtos.

## 🛠️ Tecnologias utilizadas

- Microsoft Excel
- Fórmulas e funções do Excel
- Formatação condicional
- Controle de estoque

## 📊 Funcionalidades

- Cadastro de produtos
- Controle de quantidade de entrada
- Controle de quantidade de saída
- Cálculo automático do estoque atual
- Identificação de produtos disponíveis
- Identificação de produtos indisponíveis
- Organização dos produtos por item

## 📈 Estrutura da planilha

| Campo | Descrição |
|---|---|
| Item | Número de identificação do produto |
| Produto | Nome do produto |
| UND | Unidade de medida |
| QTD Entrada | Quantidade recebida |
| QTD Saída | Quantidade vendida/retirada |
| Estoque Atual | Saldo disponível |
| Status | Disponibilidade do produto |
